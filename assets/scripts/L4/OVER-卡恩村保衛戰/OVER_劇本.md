## 二、劇情概要（GM 限定）

### 一句話摘要

> 在卡恩村抵禦王國軍隊的入侵，在安茲大人庇護下生存並反擊。

### 完整劇情背景

納薩力克地下大墳墓的統治者——安茲·烏爾·恭——在這個異世界中醒來已有一段時間。他化身為冒險者莫莫在卡恩村建立了據點。然而王國的貴族們視這個日益繁榮的「非人類控制區」為威脅，派遣軍隊前來剿滅。

輪迴者作為冒險者被安茲「招募」協助保衛卡恩村。實際上這是安茲對他們的測試——他想觀察輪迴者在壓力下的表現，以決定是否將他們視為長期盟友……或潛在威脅。

王國軍的主力包括騎士團和陽光聖典——教會的精英魔法部隊。如果他們突破了村子的防線，安茲會親自出手——但這意味著輪迴者未通過測試。

### 劇情結構類型

**混合式**：防守戰——三波王國軍攻擊 → 最終Boss戰對陽光聖典指揮官。

## 五、世界設定

### 時間線

| T+0 小時 | 甦醒於卡恩村——安茲（偽裝為莫莫）給予任務 |
| T+2 小時 | 王國軍斥候出現——第一波試探性攻擊 |
| T+6 小時 | 第二波：王國騎士主力抵達 |
| T+12 小時 | 陽光聖典到來——最終防守 |
| T+24 小時 | 若防守成功——援軍抵達 / 若失敗——安茲親自出手清理 |

### 關鍵地點

#### 地點 A：卡恩村中心（據點）

一個質樸的農村聚落。木製柵欄是最基本的防禦工事。村中央的井水是唯一的補給來源。村民們恐懼地聚集在村長家附近——他們從未經歷過真正的戰爭。

#### 地點 B：村外平原（戰場）

開闊的平原從村子邊緣延伸出去。遠處可以看見王國軍的營帳。平原上有幾處自然的掩體——小丘、灌木叢、以及一條淺淺的溪流。

#### 地點 C：村口柵欄（防線）

村子唯一的防禦工事。不結實——HP 100 / 基礎防禦 10——但能為守軍提供掩體（基礎防禦+2）。一旦柵欄被突破，敵人將直接衝入村中。

### 世界特殊規則

- **波次制**：王國軍分三波攻擊，每波間隔6小時。波次之間可以修復柵欄和治療
- **村民士氣**：村民的士氣值（初始10）。每死一名村民-2、每被突破防線一次-2。歸零時村民集體逃散
- **安茲的觀察**：安茲不會直接參戰，但他會觀察輪迴者的表現。若表現出色（S級），通關時額外獎勵。若被迫出手（F級），獎勵減半

### 主神限制條件

- 「禁止向劇情人物揭露安茲的真實身份（魔法檢測會自動阻擋此類對話）」
- 「若輪迴者攻擊無辜村民，安茲將立即轉為敵對」
