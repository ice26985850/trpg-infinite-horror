## 二、劇情概要（GM 限定）

### 一句話摘要

> 輪迴者進入屍魂界，協助黑崎一護一行人潛入瀞靈廷，在護廷十三隊隊長級的追擊下營救朽木露琪亞，並在雙殛之丘阻止處刑。

### 完整劇情背景

世界時間為屍魂界篇。朽木露琪亞因將死神之力傳給人類（黑崎一護）被護廷十三隊逮捕，並被判處雙殛處刑。輪迴者進入的時間點是浦原喜助正在訓練一護一行人之際——距離露琪亞的處刑日只剩 **72 小時**。

輪迴者必須從浦原商店出發，透過穿界門潛入屍魂界，穿越流魂街後突破瀞靈廷的防線，最終抵達雙殛之丘。途中將面對從普通死神到隊長級的層層阻攔。

護廷十三隊在此劇本中成為「制度性的敵對勢力」——多數隊長只是執行命令，而非天生邪惡。GM 需注意：更木劍八等角色具有「可敵可友」的轉向可能。

### 劇情結構類型

**混合式**：第一幕（訓練準備期）為半自由探索，第二幕（瀞靈廷潛入）為逐幕推進。

### 世界特殊規則

- **靈力體系**：輪迴者的靈力 = 決心+感知 檢定 DP。所有與死神相關的檢定可獲得靈力加成。非死神出身的輪迴者初始靈力較低，但可透過 S-03 斬魄刀訓練提升。
- **斬魄刀規則**：
 - **始解**：DP+3，附帶由角色屬性決定的元素效果（智力=鬼道系/力量=直接攻擊系/感知=感知系/敏捷=速度系）
 - **卍解**：DP×2，但持續 5 輪後需進行耐力 DC4 檢定，否則每輪承受 1d6 疲勞傷害。隊長級 NPC 在 HP < 30% 時會解放卍解。
- **鬼道系統**：智力+神秘學 檢定。
 - 破道（攻擊）：DP 依編號（1-10 = DP 5，11-30 = DP 7，31-60 = DP 9，60+= DP 11）
 - 縛道（控制）：DC 依編號（同上）
- **瞬步**：敏捷+運動 DC2 檢定，成功則當輪移動 ×3（夜一級別為 ×5～×10）
- **靈壓感知**：感知 檢定 DC2（普通死神）至 DC5（隊長級），成功可感知周遭靈壓來源

## 十、附錄

- **地圖**：請參閱 `maps/` 目錄下的 `BLEACH_WM-01.svg`、`BLEACH_EM-01.svg`、`BLEACH_BM-01.svg`、`BLEACH_BM-02.svg`
- **NPC/敵方資料**：請參閱 `BLEACH_NPC名冊.xlsx` 和 `BLEACH_敵方單位名冊.xlsx`
- **特殊規則補充**：靈力體系、斬魄刀規則、鬼道系統、瞬步規則（詳見「五、世界設定 → 世界特殊規則」）
- **GM 備忘錄**：
 - **常見卡關點**：玩家可能過度謹慎不敢潛入瀞靈廷。解法——透過時間壓力（處刑倒數）和志波空鶴的「只有一次發射機會」來推動進度。
 - **難度上調**：增加巡邏密度（每區域遭遇2次）、讓朽木白哉在牢房就出現、解鎖山本總隊長的早期參戰。
 - **難度下調**：讓夜一或一護更早加入/提供瞬步逃脫選項、減少隊長級數量、讓更木劍八因感到無趣而直接離開。
 - **玩家非常規行動**：若玩家試圖「投靠山本總隊長揭露藍染的陰謀」——GM 判斷：劇情時間點尚未揭露藍染叛變，需 DC6 智力+學識（推測可疑跡象）檢定，且證據不足可能不被採信。
- **參考資料**：《BLEACH》漫畫第 7～21 卷（屍魂界篇）、動畫第 16～63 集。
