二、劇情概要（GM 限定）

一句話摘要

輪迴者作為凡多姆海伍家的臨時調查員，在維多利亞倫敦追查開膛手傑克連環殺人案的真相。

完整劇情背景

1888 年，維多利亞時代的倫敦。白教堂區的暗巷中，連續多名妓女被殘忍殺害——外界稱兇手為「開膛手傑克」。蘇格蘭場束手無策，女王委託凡多姆海伍家調查此案。但謝爾·凡多姆海伍——年僅 13 歲的伯爵和他的萬能執事賽巴斯欽——早已察覺這不是普通的連環殺人案：受害者的子宮被精準摘除，手法不像人類所為。真相比開膛手更可怕——死神、墮落天使、以及一個瘋狂的貴族陰謀，正糾結在倫敦的霧氣之中。

劇情結構類型

混合式：開場凡多姆海伍宅邸→倫敦街頭自由調查→最終對決

| 可選目標 | 在不與死神正面交戰的情況下完成調查：+500 收集 5 個關鍵線索：+300 |

| 任務名稱 | 暗巷的刺客——白教堂區的陷阱 |

| 觸發條件 | 在白教堂區暗巷調查時 |

| 任務內容 | 潛伏在暗巷中的刺客群（威脅等級 ★，數量 1d3+1）試圖消滅調查者。刺客使用毒匕首（1d6+1 穿刺+中毒，中毒：每輪 1d4 毒素傷害，3 輪）、煙霧彈（視線遮蔽 1 輪）。需擊敗或跟蹤他們找到上級聯絡點。 |

| 時限 | 無 |

| 獎勵 | D+400。若跟蹤成功找到聯絡點：額外+300和關鍵線索。 |

| 備註 | 刺客敏捷（DEX）4，擅長偷襲（隱藏中攻擊+2 DP）。反擊可獲得他們的暗號和情報信。 |

欄位 內容

| 支線編號 | S-02 |

| 任務名稱 | 死神格雷爾——紅色的理髮師 |

| 觸發條件 | 在調查中發現死神線索後（第 3～4 小時） |

| 任務內容 | 死神格雷爾·沙多克里夫（威脅等級 ★★）——表面上是一個浮誇的紅髮理髮師，實際是掌管死亡名單的死神。他正在「協助」開膛手傑克，因為他迷戀殺戮的「美感」。

戰鬥：電鋸死神鐮刀（DP6，2d6+2 揮砍）、高速移動（一輪可移動 2 次）、死神凝視（意志豁免，難度（DC）3，失敗則恐懼 1 輪）。弱點：自戀——可用風度（PRE）+表達（Expression）檢定，難度（DC）3 分散其注意力 1 輪。 |

| 時限 | 第 5 小時前 |

| 獎勵 | C+800。若說服格雷爾反叛（難度（DC）4）：額外 C+獲得死神筆記殘頁（可看到 NPC 剩餘壽命）。 |

| 與主線關係 | 關鍵轉折——擊敗/說服格雷爾後獲得開膛手真身的情報 |

| 備註 | 格雷爾不是真正邪惡——只是病態地迷戀「紅色」。可以試著用美學話題吸引他的注意力。 |

欄位 內容

| 支線編號 | S-03 |

| 任務名稱 | 墮落天使——瘋狂的真實面貌 |

| 觸發條件 | 揭露開膛手傑克真身時（第 5～6 小時） |

| 任務內容 | 真正的開膛手傑克是一個瘋狂的貴族——安潔拉·布朗（Angela Blanc）——實際上是墮落天使（威脅等級 ★★★）在地球的化身。她收集女性子宮是為了進行「純淨儀式」，召喚更多墮落天使降臨。

戰鬥：墮落翅膀（飛行，DP7）、黑羽箭雨（範圍攻擊，DP5，2d6 暗影傷害）、召喚暗影僕從（1d2 隻 ★ 暗影，每 3 輪一次）。弱點：神聖物品（十字架、聖水、教堂祝福過的銀器）造成 2 倍傷害。 |

| 時限 | 第 6 小時前 |

| 獎勵 | C+1200。墮落天使羽根（可兌換飛行相關強化）×1d3。阻止儀式：額外+500。 |

| 與主線關係 | 主線最終目標——揭露並擊敗真正的開膛手傑克 |

| 備註 | 儀式場地位於白教堂區廢棄教堂地下。儀式若完成（第 6 小時），會召喚出額外威脅。可先破壞儀式道具來削弱最終戰難度。 |

世界特殊規則

  • 維多利亞社會禮儀：在貴族場合中行為不當（如穿著不對、言辭粗魯）會導致被逐出或遭懷疑。風度（PRE）+禮儀（Etiquette）檢定決定社交場合的成功。

  • 死神之眼：部分 NPC（賽巴斯欽、格雷爾）能看到人類的「死亡名單」——他們能看見一個人的剩餘壽命。若玩家問起，賽巴斯欽會回答：「你們的很奇怪——我看不到盡頭。」（暗示主神的介入。）

  • 惡魔契約：凡多姆海伍家與賽巴斯欽的契約是世界的核心設定——賽巴斯欽是惡魔，在謝爾完成復仇後可以吞噬他的靈魂。賽巴斯欽不能違抗謝爾的命令。

  • 蘇格蘭場的干涉：若調查行為過於張揚，蘇格蘭場會介入調查玩家本身——增加調查難度和時間壓力。

主神限制條件

  • 「禁止向劇情人物透露主神空間的存在」

  • 「本世界可使用維多利亞時代武器（手槍、刀劍），但禁用現代化自動武器」

  • 「在公眾場合使用超自然能力會引起恐慌和蘇格蘭場追捕」

七、NPC 設計深度指引

賽巴斯欽·米卡艾利斯（Sebastian Michaelis）——惡魔執事

維度 設計指引
核心特質 完美到令人毛骨悚然的執事、對謝爾以外的一切漠不關心、優雅的惡魔。
互動層級 表層：作為接待者提供案件情報。中層：若玩家展現能力，會提供更多實質協助。深層：極少——惡魔不會真正信任人類。
關鍵觸發點 若玩家有效率的調查（連續 3 次檢定成功），賽巴斯欽會說：「不錯——對人類來說。」並提供額外情報。
戰鬥定位 惡魔——DP10，幾乎不會被擊中。但不會主動參戰（除非謝爾下令）。一輪 3 動。
