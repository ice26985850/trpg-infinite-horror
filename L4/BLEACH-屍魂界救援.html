二、劇情概要（GM 限定）

一句話摘要

輪迴者進入屍魂界，協助黑崎一護一行人潛入瀞靈廷，在護廷十三隊隊長級的追擊下營救朽木露琪亞，並在雙殛之丘阻止處刑。

完整劇情背景

世界時間為屍魂界篇。朽木露琪亞因將死神之力傳給人類（黑崎一護）被護廷十三隊逮捕，並被判處雙殛處刑。輪迴者進入的時間點是浦原喜助正在訓練一護一行人之際——距離露琪亞的處刑日只剩 72 小時。

輪迴者必須從浦原商店出發，透過穿界門潛入屍魂界，穿越流魂街後突破瀞靈廷的防線，最終抵達雙殛之丘。途中將面對從普通死神到隊長級的層層阻攔。

護廷十三隊在此劇本中成為「制度性的敵對勢力」——多數隊長只是執行命令，而非天生邪惡。GM 需注意：更木劍八等角色具有「可敵可友」的轉向可能。

劇情結構類型

混合式：第一幕（訓練準備期）為半自由探索，第二幕（瀞靈廷潛入）為逐幕推進。

世界特殊規則

  • 靈力體系：輪迴者的靈力 = 決心+感知 檢定 DP。所有與死神相關的檢定可獲得靈力加成。非死神出身的輪迴者初始靈力較低，但可透過 S-03 斬魄刀訓練提升。
  • 斬魄刀規則：
  • 始解：DP+3，附帶由角色屬性決定的元素效果（智力=鬼道系/力量=直接攻擊系/感知=感知系/敏捷=速度系）
  • 卍解：DP×2，但持續 5 輪後需進行耐力 DC4 檢定，否則每輪承受 1d6 疲勞傷害。隊長級 NPC 在 HP < 30% 時會解放卍解。
  • 鬼道系統：智力+神秘學 檢定。
  • 破道（攻擊）：DP 依編號（1-10 = DP 5，11-30 = DP 7，31-60 = DP 9，60+= DP 11）
  • 縛道（控制）：DC 依編號（同上）
  • 瞬步：敏捷+運動 DC2 檢定，成功則當輪移動 ×3（夜一級別為 ×5～×10）
  • 靈壓感知：感知 檢定 DC2（普通死神）至 DC5（隊長級），成功可感知周遭靈壓來源

  • 「若殺死非敵對的無關死神（非正當防衛），扣除 1000每人」

七、關鍵場景

場景結構說明

本劇本採 混合式：第一幕（0～18 小時）包含準備與訓練的自由探索，第二幕（18～72 小時）為逐幕推進的潛入與戰鬥。

第一幕：準備與訓練（0～18 小時）

欄位 內容
場景編號 S01
場景名稱 浦原的邀請
觸發條件 劇本開始
GM 朗讀文本 「你睜開眼，發現自己躺在一個昏暗的地下空間。頭頂懸掛著散發微光的符咒，空氣中瀰漫著淡淡的靈子氣息。一個戴著綠白條紋帽、腳踩木屐的男人用扇子遮著半張臉，笑瞇瞇地看著你。『哎呀哎呀，醒了嗎？歡迎來到浦原商店——或者說，我的地下訓練場。』」
可互動元素 浦原喜助（對話——獲得任務說明和一護的計畫）、穿界門（目前關閉，需要準備完成後開啟）、訓練設備、桌上的筆記

第二幕：潛入瀞靈廷（18～72 小時）

場景 S04：流魂街的混亂

欄位 內容
場景編號 S04
場景名稱 流魂街——天堂的另一面
觸發條件 抵達流魂街
GM 朗讀文本 「流魂街的街道擁擠而嘈雜。平民們匆忙躲避——不是因為你們，而是遠處天邊出現的黑色裂縫。一陣刺耳的嚎叫從裂縫中傳來，緊接著是巨大的白色面具從黑暗中探出——大虛（Menos Grande）正在入侵流魂街的外圍區域。」
可互動元素 志波空鶴（對話——獲得大砲協助的前提）、流魂街居民（可協助疏散，每10名獲得100獎勵點數）、黑色裂縫（大虛的入口）

分支選項 擊敗大虛 → 志波空鶴提供大砲協助（跳過瀞靈廷正門守衛+獲得 B1）；不戰鬥/繞過 → 必須從正門突破（遭遇 1 名隊長級+1d6 普通死神）
過場條件 獲得進入瀞靈廷的方式

遭遇 著陸後：落點隨機遭遇。投 1d6——1-2 = 無（偏僻區域），3-4 = 1d3 席官+1d4 普通死神，5 = 1 名副隊長+1d4 普通死神，6 = 1 名隊長級！
過場條件 團隊著陸並完成初始遭遇

場景 S06：牢房突入——初遇戀次

欄位 內容
場景編號 S06

觸發條件 抵達六番隊牢房區域

可互動元素 牢房（露琪亞在其中），阿散井戀次（對話——DC4 操控+交際可說服轉向，或強制戰鬥），守衛室（搜索可獲得牢房鑰匙和 1d6×100 物資）

分支選項 說服成功 → 戀次轉為協助方（S-02完成/獲得B1）+露琪亞被釋放；強制戰鬥 → 擊倒戀次和守衛獲得相同結果但可能引發更高等級警報（1d6 輪內 1 名隊長級抵達）；潛行繞過（敏捷+隱藏 DC3）→ 避開戀次但露琪亞仍在封印中
過場條件 露琪亞被救出或決定繞過

場景 S07：中庭遭遇——隊長級攔截

欄位 內容
場景編號 S07

GM 朗讀文本 「走出牢房區，你們踏上中庭的迴廊。櫻花無聲地飄落——但空氣中瀰漫著令人窒息的靈壓。一個高大的身影從迴廊另一端走來，肩上扛著鋸齒狀的斬魄刀，左眼的眼罩格外醒目。他停下腳步，露出一個狂野的笑容。『找到了——最強的那個，站出來。』」
可互動元素 更木劍八（可敵可友——不攻擊弱者/只挑戰強者）、副隊長草鹿八千流（蹲在一旁的屋簷上 / 不參戰）
遭遇 可選 BOSS 戰：更木劍八（隊長級 ★★★★★）。若選擇戰鬥：這是純粹的正面對決，劍八會逐步解放戰力——前 3 輪保持眼罩（DP 正常），第 4 輪解開眼罩（DP+3），HP<50% 後使用始解（DP+5）。
基因鎖相關 基因鎖提示：強烈建議基因鎖四階（決心 DC5）對抗劍八。劍八的靈壓爆氣可範圍壓制（DC4 決心失敗則 DP-2）。開啟四階可抵抗靈壓並獲得 DP+2 的戰鬥直覺。若想規避此戰——讓全員壓低靈壓（決心 DC3），劍八會認為「無趣」而離開。
分支選項 戰鬥勝利 → A1（可選目標②完成）+劍八的尊重（可能協助對抗其他隊長）；壓低靈壓避戰 → 跳過此場景（無獎勵）；說服「有更強的對手在雙殛之丘」→ 操控+交際 DC4，劍八離開去雙殛（雙殛場景中可能變成混戰第三方）
過場條件 劍八戰結束或避開

場景 S08：雙殛之丘——最終決戰

欄位 內容
場景編號 S08
場景名稱 雙殛之怒
觸發條件 抵達雙殛之丘（時限 T+72 前）
GM 朗讀文本 「你終於抵達了雙殛之丘的山腳。抬頭望去，巨大的火焰之矛正在山頂凝聚——雙殛的處刑即將開始。石階上方，你能感受到數個強大的靈壓。其中一個——冰冷而鋒利，如同千片刀刃——朽木白哉。而在更上方，一道如太陽般灼熱的靈壓靜靜燃燒著——總隊長，山本元柳齋重國。」
可互動元素 處刑架（力量 DC6 或斬魄刀始解 DP12 可破壞雙殛的火焰矛）、一護（關鍵時刻介入對抗白哉）、周邊的柱子（掩體 基礎防禦+2）
遭遇 強制 BOSS 戰：朽木白哉（隊長級 ★★★★★）+2 名副隊長（★★★★）。白哉的千本櫻為全方向攻擊（基本閃避 DC+2）。HP < 40% 時解放卍解「千本櫻景嚴」——DP×2 / 全螢幕範圍 / 每輪自動傷害 2d8。若團隊接近 T+70 後才到達，山本總隊長（★★★★★+）將加入戰鬥。
基因鎖相關 基因鎖提示：強烈建議全部成員開啟基因鎖四階（決心 DC5）。白哉的卍解為全螢幕攻擊，基因鎖四階可獲得「感知預判」（回合優先級+2），讓你能在千本櫻全開前找到空隙。對抗山本總隊長時——基因鎖四階為最低要求，總隊長的流刃若火卍解可造成環境持續傷害（每輪 2d6 火焰）無法完全免疫。
分支選項 擊敗白哉 → 雙殛被破壞，露琪亞獲救，主線完成。若山本總隊長在場——不需要完全擊敗，只要破壞雙殛即可觸發撤退劇情（一護/夜一協助逃生）
過場條件 雙殛被破壞+露琪亞安全 → 劇本通關
