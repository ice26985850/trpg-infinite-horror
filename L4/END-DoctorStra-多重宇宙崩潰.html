二、劇情概要（GM 限定）

一句話摘要

在多重宇宙崩潰中保護地球-616維度，對抗失控的緋紅女巫。

完整劇情背景

多重宇宙正在崩潰。一個來自平行宇宙的奇異博士的屍體出現在地球-616——這是第一個警告信號。很快，不同宇宙開始侵入彼此——建築物在不同現實版本之間閃爍，物理法則開始失效。

罪魁禍首是汪達·馬克西莫夫（緋紅女巫）——她利用黑暗神書（Darkhold）的力量試圖尋找一個她可以成為母親的宇宙，卻在過程中撕裂了多重宇宙的結構。

輪迴者必須協助奇異博士和王在三個維度交匯點穩定現實結構，同時對抗來自各宇宙的混沌造物。最終必須面對緋紅女巫——但擊敗她不是唯一的選擇。救助她——將她從黑暗神書的腐化中解放——是更困難但更好的結局。

劇情結構類型

混合式：同時防守三個維度交匯點 → 每個點都是一場獨立戰鬥。

五、世界設定

時間線

| T+0 小時 | 甦醒於紐約聖所——奇異博士正在分析平行宇宙現象 | | T+6 小時 | 第一個維度交匯點出現——混沌魔像入侵 | | T+12 小時 | 美國小姐抵達——星形門能力解鎖 | | T+24 小時 | 第二、第三交匯點同時受到攻擊 | | T+36 小時 | 緋紅女巫開始直接進攻聖所 | | T+48 小時 | 多重宇宙完全崩潰——任務失敗 |

關鍵地點

地點 A：紐約聖所（據點）

奇異博士的紐約根據地。充滿了魔法文物和傳送門。這裡是第一維度交匯點的所在地。

地點 B：卡瑪泰姬

喜馬拉雅山中的秘術聖地。圖書館中有大量關於維度穩定的知識。王在此提供支援。

地點 C：旺達戈爾山（最終）

汪達的隱居地。被混沌魔法和黑暗神書的符文扭曲的現實包圍。最終對決的地點。

世界特殊規則

  • 現實崩潰：每經過12小時，1個新的維度交匯點會自動出現——必須派人防守
  • 混沌魔法：汪達的魔法可以「重寫」現實——GM可在她的回合中更改1條場地規則（如「重力方向改變」或「火焰免疫變火焰弱點」）
  • 星形門：美國小姐可以開啟跨維度傳送——但每次使用後需要2小時冷卻

主神限制條件

  • 「禁止使用黑暗神書（輪迴者若嘗試閱讀——立即進行決心DC6/失敗被腐化）」
  • 「若美國小姐死亡——失去跨維度逃脫途徑」

欄位 內容
場景編號 S01

可互動元素 奇異博士（任務說明+維度交匯點情報）、聖所文物（可借用魔法裝備/每名隊員限1件/智力+神秘學DC3激活）、窗口（觀察可感知DC4發現不同維度的入侵點）
遭遇 無即時戰鬥——引導階段
基因鎖相關 無——引導階段

八、獎勵結算

場景 S03：遭遇——維度交匯點防守——混沌入侵

欄位 內容
GM 朗讀文本 「聖所的魔法警報驟然響起。地面上憑空出現了一個旋轉的混沌漩渦——從中爬出了扭曲的、像是融化的石像般的生物。混沌魔像。它們的形狀不停地流動和變化——像是這個宇宙在拒絕它們的存在。」
可互動元素 聖所結界（可激活——智力+神秘學DC3/提供AC+2範圍）、魔法書架（可推倒——阻擋魔像移動路線）、傳送環（奇異博士可瞬間移動1名隊員到任何位置/每輪限1次）
遭遇 混沌魔像 ×1d2（★★★★）+混沌碎片 ×1d6（★★★）。混沌魔像每2輪會「現實坍縮」——在10ft半徑內造成3d10混沌傷害。
基因鎖相關 基因鎖提示：基因鎖三階（決心DC4）：用於感知混沌魔像的坍縮預兆——在坍縮前1輪會有空間波動，基因鎖可提前感知並獲得反射DC-3。
過場條件 所有混沌魔像被消滅

場景 S08：最終決戰——緋紅女巫——混沌之巔

欄位 內容
GM 朗讀文本 「旺達戈爾山的山頂——這裡的現實已經完全破碎。你周圍的空間不斷地切換——一會兒是燃燒的紐約，一會兒是寧靜的農田（汪達夢想中的家），下一秒又變回黑暗的虛空。汪達站在破碎現實的中心——她的眼睛散發著暗紅色的光芒，黑暗神書的符文在她的皮膚上流動。「沒有人能阻止我找到我的孩子——沒有人。」」
可互動元素 黑暗神書的殘頁（若S-03完成——可進行說服路線/交涉DC6/成功則「救助汪達」結局）、破碎的現實碎片（可作為掩體但每2輪變換位置）、美國小姐（可開啟最後的星形門——若選擇撤退而非戰鬥/消耗B1）
遭遇 強制 BOSS 戰：緋紅女巫（★★★★★+）。HP 200 / DP 14。每3輪重寫1條現實規則——GM可更改元素抗性/地形效果/重力方向。心靈控制（意志DC6）可操控1名目標。HP<30%時解放全部混沌能量——每輪對全場造成4d10混沌。
基因鎖相關 基因鎖提示：基因鎖四階（決心DC5）：全員必須開啟。汪達的現實改寫是此戰的核心挑戰——基因鎖四階可讓輪迴者在現實被改寫的瞬間感知到「什麼改變了」，從而快速適應新條件（獲得1輪適應期而非吃驚）。
過場條件 擊敗汪達 或 成功「救助汪達」（說服DC6+展示黑暗神書破解結果）→ 劇本通關
