二、劇情概要（GM 限定）

一句話摘要

協助卡德加關閉燃燒軍團的傳送門，阻止阿克蒙德降臨艾澤拉斯。

完整劇情背景

燃燒軍團再次入侵艾澤拉斯。從扭曲虛空中打開的巨大傳送門正在源源不斷地輸送惡魔大軍——地獄犬、末日守衛、以及深淵領主們正在摧毀一切。大法師卡德加集結了最後的守護者力量，但關閉傳送門需要守護者在三個關鍵節點同時施法——而他只有一個人。

輪迴者進入的正是這個危急時刻。他們必須協助卡德加守護三個法術節點不被惡魔破壞，同時消滅足夠多的軍團指揮官以減弱傳送門的能量。守護者麥迪文——雖然他曾經開啟過黑暗之門——如今站在人類一方，願意用他的知識幫助關閉它。

但如果阿克蒙德成功從傳送門中完全顯現——一切都將結束。

劇情結構類型

混合式：三個法術節點需要同時守護 → 每個節點為一個獨立的戰鬥場景。

五、世界設定

時間線

| T+0 小時 | 甦醒於達拉然廢墟——卡德加正在準備傳送門關閉儀式 | | T+3 小時 | 第一個法術節點開始——地獄犬先鋒來襲 | | T+6 小時 | 麥迪文抵達——提供加速咒語 | | T+12 小時 | 深淵領主出現——第二節點防守戰 | | T+18 小時 | 阿克蒙德開始通過傳送門顯現——第三節點最終防守 | | T+24 小時 | 傳送門完全打開——任務失敗 |

關鍵地點

地點 A：達拉然廢墟（起始點／第一節點）

曾經的魔法之城如今半數化為廢墟。卡德加在城中央的魔法陣上刻畫著巨大的封印符文。周圍是燃燒的建築和散落的魔法書頁。

地點 B：麥迪文之塔（第二節點）

孤獨的石塔聳立在荒原上。塔頂的觀星台可以看到傳送門的全景。麥迪文在這裡準備第二個封魔法陣。

地點 C：黑暗之門遺址（第三節點／最終）

曾經連通德拉諾的傳送門廢墟——如今燃燒軍團用同一處空間裂縫構建了入侵通道。扭曲虛空的光芒從裂縫中射入這個世界。

世界特殊規則

  • 傳送門能量：每經過6小時，軍團援軍強度+1（初始★★→最終★★★★）
  • 節點防守：每個節點需要10輪的詠唱時間。被攻擊會打斷——每被打斷1輪進度倒退2輪
  • 麥迪文的犧牲：如果情況危急，麥迪文可以犧牲自己完全關閉傳送門——但這會導致團隊失去智慧指導

主神限制條件

  • 「禁止向劇情人物透露主神空間的存在」
  • 「若三個法術節點全部失守，傳送門將不可逆地打開」

八、獎勵結算

場景 S03：遭遇——節點守護——深淵領主來襲

欄位 內容
GM 朗讀文本 「第二個節點剛布下，天空中就傳來了一聲低沉的咆哮。一隻巨大的身影從傳送門中擠出——它比任何建築物都要高，渾身燃燒著綠色的地獄火。深淵領主。它舉起手中的巨型戰錘，對著節點發出了戰吼。地面在你腳下顫抖。」
可互動元素 節點（HP 150 / 基礎防禦 14——必須保護）、周圍的魔法塔（可推倒對深淵領主造成DP 10擊倒/力量DC5）、卡德加（提供遠程火力支援——每輪對1名敵方DP 8奧術）
遭遇 深淵領主（★★★★）×1+地獄犬 ×1d4。深淵領主每2輪釋放惡魔火焰（DP 9 / 範圍30ft / 4d6火焰）。
基因鎖相關 基因鎖提示：基因鎖三階（決心DC4）：建議用於定位深淵領主的攻擊盲區——在巨錘蓄力時獲得1輪無敵窗口。
過場條件 保護節點10輪或擊敗深淵領主

場景 S08：最終決戰——阿克蒙德降臨

欄位 內容
GM 朗讀文本 「第三個節點——也是最後的希望。卡德加和麥迪文同時開始詠唱最終的封印咒。但就在這時，傳送門猛烈震動——一隻覆蓋著火焰的巨大手臂從裂縫中伸出。阿克蒙德。汙染者。他正在將自己從扭曲虛空中拉入這個世界。他的眼睛鎖定了你們——鎖定了法術節點。」
可互動元素 節點（HP 200 / 必須在10輪內保護——完成S-02可縮短至5輪）、麥迪文的屏障（為節點提供暫時無敵/持續3輪/只能使用1次）、卡德加的法陣（若隊員協助引導能源——智力+神秘學DC4可加快詠唱每輪0.5輪）
遭遇 強制 BOSS 戰：阿克蒙德（★★★★★+）——未完全降臨狀態。HP 200（本體）/ DP 12。每3輪軍團召喚援軍。需要在傳送門完全打開前保護節點。阿克蒙德完全降臨後HP=300/DP=14/每輪自動攻擊。
基因鎖相關 基因鎖提示：基因鎖四階（決心DC5）為最低要求。阿克蒙德的死亡一指為即死級威脅——基因鎖四階可在施法前1輪感知魔力凝聚，獲得DC-3反射豁免來規避。
過場條件 傳送門完全關閉 → 劇本通關
